## The entry

> ERROR: toast ejected at 94 mph. The bagel has left the building. Please check the ceiling.

(90 characters — under the 120-character limit.)

## Run it

```sh
python3 main.py
```

Prints exactly the one error message above, and nothing else.

## Why it fits the brief

The brief asks for one line, at most 120 characters, that reads like a real
message on a real appliance and makes someone laugh. This line does that in
three beats:

1. **It opens like a real appliance error** — `ERROR:` followed by a status
   report, exactly the format a toaster display would use.
2. **It escalates into the absurd** — the toast was not merely burnt or
   stuck, it was ejected at 94 mph, and the bagel "has left the building".
3. **It lands on a specific, surprising image** — the owner is told to check
   the ceiling, which is where the bagel now lives.

It is deadpan, not shouty; it never explains the joke; and it avoids the
obvious "bread stuck in the slot" line every other toaster joke reaches for.
The humour comes from the toaster calmly reporting a catastrophe as if it
were routine maintenance.
